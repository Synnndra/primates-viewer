========================================
  HOW TO GET YOUR FREE HELIUS API KEY
========================================

This takes only 2 MINUTES!

WHY HELIUS?
-----------
MidEvils are "compressed NFTs" (cNFTs) which are stored differently
on Solana. Helius has FREE support for compressed NFTs!


STEP 1: Sign Up for Helius
---------------------------
1. Open your browser
2. Go to: https://helius.dev
3. Click "Get Started" or "Sign Up"
4. Sign up with your email


STEP 2: Create an API Key
--------------------------
1. After signing in, you'll see your dashboard
2. Look for "API Keys" in the menu
3. Click "Create New API Key" or "New Project"
4. Give it a name: "MidEvil Viewer" (or anything you want)
5. Click "Create"
6. You'll see your API key - a long random string
7. Click "Copy" to copy it


STEP 3: Add API Key to Your App
---------------------------------
1. Open the file: app.js
   - You can right-click it and choose "Open with Notepad"
   - Or open it in Cursor

2. Find line 45 (near the top of the file)
   It says: const HELIUS_API_KEY = 'YOUR_HELIUS_API_KEY';

3. Replace YOUR_HELIUS_API_KEY with your actual key
   BEFORE: const HELIUS_API_KEY = 'YOUR_HELIUS_API_KEY';
   AFTER:  const HELIUS_API_KEY = 'your-copied-key-here';

   ⚠️ KEEP THE QUOTES! ⚠️

4. Save the file (Ctrl+S or File > Save)


STEP 4: Run Your App
--------------------
1. Double-click: start.bat
2. Open browser, go to: http://localhost:3000
3. Enter your Solana wallet address
4. Click "View NFTs"
5. See all your MidEvils! 🎉


Need Help?
----------
If you see: "Please get a FREE Helius API key"
→ You haven't added your API key to app.js yet

If you see: "Failed to fetch NFTs"
→ Make sure you copied the FULL key and kept the quotes

Questions? The README.md file has more details!
